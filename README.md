# Yared Ababu — Developer Portfolio

A dark, premium, responsive developer portfolio built with React, TypeScript, Vite, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

Open `src/data.ts` and update:

- `profile.linkedin` with your exact LinkedIn profile URL.
- `profile.email` with a professional email address.
- Confirm every project description and repository URL.
- Add or remove projects based on what is publicly available and ready to demonstrate.

The portfolio intentionally does not invent work experience, client results, LeetCode totals, or proficiency levels.

## Deploy

You can deploy the `dist` folder to Vercel, Netlify, or another static hosting provider. Connect the repository, use `npm run build` as the build command, and `dist` as the output directory.

## Before sharing with recruiters

- Check every repository link.
- Add your LinkedIn and email.
- Add screenshots or short demos of the strongest projects.
- Make sure each repository has a clear README and setup instructions.
- Test the production site on mobile.
